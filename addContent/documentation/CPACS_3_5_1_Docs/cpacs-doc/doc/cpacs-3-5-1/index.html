CPACS 3.5.1

Release in 2026

  • Refinement of the systems definition introduced in CPACS 3.5
    • update the geometry concept for predefined systemElements
    • add multiSegmentShapes and external CAD references
    • allow combined shapes in predefined systemElements with individual transformations
    • remove aircraft-level scaling for instantiated generic systems in order to avoid ambiguous semantics for mass, center of gravity, and inertia properties
  • Refinement of decks to better align with systems
    • harmonize the handling of deckElements and systemElements
    • replace the previous boundingBox-based approach with the same general geometry building blocks used for systems
    • replace the former 2D-only deck instantiation concept by a consistent 3D transformation
    • allow cargo containers to be handled as regular deck elements
  • Refinement of the fuelTanks definition introduced in CPACS 3.5
    • move vessel-based tanks to vehicles/aircraft/model/fuelTanks
    • replace XML nesting below fuselage by placement via parentUID, allowing tanks to be attached to fuselages, wings, nacelles, and other geometry parents
    • rework the internal tank definition around vessels
    • improve support for structural definitions on vessel level
  • update and consolidate example files for systems and fuel tank use cases
  • add documentation and build improvements, including tool-specific documentation support and updated build instructions
