stringArrayBaseType

complexType · extension stringBaseType · value xsd:string

String array base type

Base type for string array nodes (including maptype array attribute)

DEPRECATED: As of CPACCS version 3.3, the mapType attribute is set to optional to ensure the compatibility of older data records. However, since the type is uniquely defined via the XSD, the attribute is superfluous and will therefore be completely omitted in future versions.
