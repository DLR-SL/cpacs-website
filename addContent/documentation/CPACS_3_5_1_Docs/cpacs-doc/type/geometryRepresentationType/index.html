geometryRepresentationType

simpleType · restriction xsd:string

Allowed values

ValueDescription
physicalThe geometry represents the intended physical shape of the element. It may be used for visualization and, if applicable, for the evaluation of geometric properties such as volume, mass, or center of gravity.
envelopeThe geometry represents an enclosing or simplified outer envelope of the element rather than its detailed physical shape. It is primarily intended for installation space, packaging, and clearance considerations.
placeholderThe geometry is a simplified placeholder intended primarily for visualization when the actual geometry of the element is not yet known. Consumers should not use it as an authoritative representation of the physical shape or installation envelope.
