transformationType

complexType · extension complexBaseType · all

Transformation

Set of transformations. The order of the transformations is scaling -> rotation -> translation, and they are executed in this order. Any of them can be omitted; it will be replaced by its defaults.

Transformations are always executed relative to the child not the parent. I.e. a scaling does not have an influence on the parent item. For example in the outer geometry of a wing the element scaling does not influence the section. Scaling does also not effect rotation and translation.
